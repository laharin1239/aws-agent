# aws-agent


A local AWS cost analysis agent. A small language model running on your own machine (via [Ollama](https://ollama.com)) decides **which tool to call**, and **pandas does all the math**. The model never calculates, estimates or guesses numbers itself, so the dollar amounts in its answers always come straight from the data.

> The cost data in this repo is **synthetic** (generated by `generate_data.py`). It is not real AWS billing data.

## How it works

```
You ask a question
      |
      v
Local LLM (qwen2.5:3b via Ollama) picks a tool + arguments
      |
      v
tools.py runs the tool with pandas  ->  returns exact numbers
      |
      v
LLM explains the result in a short answer
```

## Project structure

| File | Purpose |
|------|---------|
| `generate_data.py` | Creates `aws_costs.csv`: 90 days of daily costs for 6 services in 2 regions, with 3 planted anomalies |
| `tools.py` | Deterministic pandas tools the model can call |
| `agent.py` | Chat loop that connects the Ollama model to the tools |
| `aws_costs.csv` | Generated dataset (1,080 rows: date, service, region, cost_usd) |

## Available tools

- **`total_cost(service, start_date, end_date)`**: total spend, optionally for one service and/or a date range (YYYY-MM-DD)
- **`top_services(n)`**: the n most expensive services overall
- **`cost_trend(service)`**: monthly totals and month-over-month % change
- **`detect_anomalies(z_threshold)`**: finds days where a service+region cost is unusually far from its own average (z-score, default threshold 3.0)

## Setup

**1. Install Python packages**

```bash
pip install ollama pandas numpy
```

**2. Install Ollama and download the model**

Install Ollama from https://ollama.com, then:

```bash
ollama pull qwen2.5:3b
```

**3. Generate the data** (skip if `aws_costs.csv` is already present)

```bash
python generate_data.py
```

**4. Run the agent**

```bash
python agent.py
```

Type `exit` or `quit` to leave.

## Example questions

- What is the total cost across all services?
- How much did EC2 cost?
- What are the top 3 most expensive services?
- Show the monthly cost trend for Lambda.
- Are there any cost anomalies?
- How much did S3 cost between 2026-09-01 and 2026-09-30?

## Planted anomalies

The dataset contains three deliberate spikes that `detect_anomalies` should find:

| Date | Service | Region | Spike |
|------|---------|--------|-------|
| 2026-09-12 | EC2 | ap-south-1 | 4x normal |
| 2026-10-03 | DataTransfer | us-east-1 | 6x normal |
| 2026-10-20 | Lambda | ap-south-1 | 8x normal |

## Notes

- You can change the model by editing `MODEL` in `agent.py`. Any Ollama model that supports tool calling will work, but larger models follow instructions more reliably.
- The data covers 2026-08-01 to 2026-10-29. Dates outside this range return a clear error to the model.
- To use real AWS data, export a Cost Explorer or CUR report to a CSV with the same four columns (`date`, `service`, `region`, `cost_usd`) and replace `aws_costs.csv`.
